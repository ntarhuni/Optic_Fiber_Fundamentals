# Fiber-Optics Concept Lab

Interactive Streamlit app for **Chapter 2 (Optics Review)** and **Chapter 3 (Lightwave Fundamentals, Part 1)**.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Modules
| Chapter | Module | What you can do |
|---|---|---|
| 2 | Refraction & Snell | ray diagram, TIR, θt curve, speed/λ in materials |
| 2 | Lenses & GRIN rods | lensmaker eq., ray tracing (real/virtual image), quarter-pitch collimate/focus |
| 2 | Numerical aperture | receiver acceptance angle, off-axis beam test, NA↔θ table, fiber NA |
| 2 | Diffraction & Gaussian | Airy spot 2.44λf/D, Gaussian beam, lens-to-fiber coupling |
| 3 | EM waves | k, λ, ω, lossy wave, dB/km ↔ α |
| 3 | Source spectrum | Δλ ↔ Δf, source comparison |
| 3 | Material dispersion | M(λ), pulse spread, pulse-broadening simulation |
| 3 | Bandwidth & data rate | modulation loss, RZ/NRZ eye diagram, PSD, link calculator |
| 3 | Polarization | 3-D E-field, ellipse, unpolarized, Malus |
| 3 | Resonant cavities | standing waves, mode spacing, laser mode spectrum |
| 3 | Fresnel reflection | ρ, τ, R, ρp/ρs vs angle, Brewster, interface loss |
| 3 | Critical angle | TIR, evanescent wave, fiber-guidance ray demo |
| – | Practice problems | 17 randomised problem types, auto-checked, worked solutions |
| – | Formula sheet | all slide equations |

Extensions beyond the slides (coherence length, Malus's law, circular/elliptical polarization, fiber NA) are labelled in the app.
